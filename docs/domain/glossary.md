# Słownik pojęć domenowych

Polskie definicje i angielskie nazwy tworzą jeden słownik, nie tłumaczenie wymagań. Właścicielem reguły jest wskazana kanoniczna specyfikacja; słownik jest odniesieniem pochodnym. Nazwy są tożsamościami pojęć, **nie nakazem tworzenia nowych tabel, kolekcji, pól ani schematów**. Stan realizacji znajduje się wyłącznie w sekcjach zadań w [projektach](../projects/README.md); dawne Issue są źródłem historycznym.

Czytaj także [indeks](../index.md), [przykłady](../reference-examples.md), [otwarte decyzje](../decisions.md) i [opis Workforce Planning](../workforce-planning.md).

| Termin polski / English identity | Znaczenie i granica | Właściciel kontraktu i źródło |
|---|---|---|
| Plan produkcji / `ProductionPlan` | Zapisane pozycje ilości i terminów gotowości, powiązane z opublikowanymi wersjami receptur. Nie jest wynikiem kalkulatora, grafikiem osób ani wykonaniem partii. | [PLN-REQ-002](../specs/production-plans.md#pln-req-002), [PLN-AC-001](../specs/production-plans.md#pln-ac-001), [REC-REQ-012](../specs/recipes.md#rec-req-012) |
| Zatwierdzona wersja planu / approved `ProductionPlan` version | Konkretna wersja udostępniana odbiorcom z identyfikatorem i wersją. Nowy szkic nie zastępuje jej przed zatwierdzeniem następcy. Zatwierdzenie ilości nie potwierdza wykonalności zasobów ani nie tworzy rzeczywistej partii. | [PLN-REQ-001](../specs/production-plans.md#pln-req-001), [PLN-REQ-004](../specs/production-plans.md#pln-req-004), [PLN-AC-002](../specs/production-plans.md#pln-ac-002) |
| Grafik zmiany / `ShiftPlan` | Planowane godziny i przerwy konkretnej osoby, z własną publikacją i historią. Nie jest planem ilości produkcji ani dowodem obecności. Jeden model dla 1–N osób; szacunek wsteczny nie gwarantuje wykonalności. | [WRK-REQ-001](../specs/workforce.md#wrk-req-001), [WRK-REQ-005](../specs/workforce.md#wrk-req-005), [WRK-REQ-009](../specs/workforce.md#wrk-req-009), [WRK-AC-002](../specs/workforce.md#wrk-ac-002) |
| Indywidualny zapis pracy/obecności / `WorkSession` | Rzeczywiste godziny osoby, przerwy i kontrolowane korekty. Obecność, płatna praca i formalna ewidencja nie są synonimami. Domyślnie dane operacyjne/eksport; formalne użycie wymaga osobnej weryfikacji. | [WRK-REQ-012](../specs/workforce.md#wrk-req-012), [WRK-REQ-013](../specs/workforce.md#wrk-req-013), [WRK-REQ-015](../specs/workforce.md#wrk-req-015), [WRK-AC-012](../specs/workforce.md#wrk-ac-012) |
| Partia ciasta / `ProductionBatch` | Osobny zapis wykonania związany z niezmienną opublikowaną wersją receptury i planowaną masą/liczbą sztuk. Sam plan ani animacja nie dowodzą wykonania. | [EVT-REQ-003](../specs/production-records.md#evt-req-003), [EVT-AC-001](../specs/production-records.md#evt-ac-001), [PLN-REQ-001](../specs/production-plans.md#pln-req-001) |
| Etap / `phase` | Okres technologiczny, np. fermentacja. Może zawierać krótkie operacje aktywne; czas pasywny nie jest ciągłą pracą ludzi. | [PRC-REQ-001](../specs/process-execution.md#prc-req-001), [EVT-AC-002](../specs/production-records.md#evt-ac-002) |
| Operacja / `task` | Konkretna czynność, np. składanie lub formowanie. Może trwać wewnątrz etapu bez jego zakończenia. Czas operacji i nakład osobominut to różne wyniki. | [EVT-REQ-004](../specs/production-records.md#evt-req-004), [EVT-AC-004](../specs/production-records.md#evt-ac-004) |
| Odcinek nakładu pracy / `LaborSegment` | Okres obowiązywania liczby osób na operacji; nakład = czas × `workerCount`. Zmiana obsady tworzy kolejny odcinek; odcinki jednej operacji nie nakładają się. Anonimowe deklaracje nie identyfikują unikalnych osób ani nie zastępują `WorkSession`. Współdzielenie wymaga jawnej alokacji do dokładnych kosztów. | [EVT-REQ-005](../specs/production-records.md#evt-req-005), [WRK-REQ-001](../specs/workforce.md#wrk-req-001), [ECO-REQ-001](../specs/economics-investment.md#eco-req-001), [MAP-AC-013](../specs/flow-map-demo.md#map-ac-013) |
| Wersja receptury / `recipeVersion` | Opublikowana wersja pełnej samodzielnej receptury, z masami i dodatnim całkowitym uzyskiem. Masa porcji jest pochodną sumy mas / uzysk, nie drugim niezależnym źródłem. Odnośnik do bazy nie dodaje składników. | [REC-REQ-001](../specs/recipes.md#rec-req-001), [REC-REQ-002](../specs/recipes.md#rec-req-002), [REC-AC-005](../specs/recipes.md#rec-ac-005) |
| Historyczna kompozycja składników / historical ingredient composition | Zamrożone w opublikowanej wersji wartości klasyfikacji, mąki/wody zakwasu, typów mąki i mas. Stabilna relacja do surowca nie uprawnia do przeliczenia historii z jego bieżącej klasyfikacji. Brak składu zakwasu nie daje dokładnych procentów. | [REC-REQ-001](../specs/recipes.md#rec-req-001), [REC-REQ-011](../specs/recipes.md#rec-req-011), [REC-AC-004](../specs/recipes.md#rec-ac-004) |
| Identyfikator produktu sprzedażowego / `SKU` | Stabilna tożsamość produktu do przypięcia sprzedaży i bilansu; nie identyfikator partii ani wersji receptury. Plan wskazuje SKU, gdy mapowanie istnieje; brak mapowania blokuje eksport wymagający SKU. | [SAL-REQ-001](../specs/sales-returns.md#sal-req-001), [PLN-REQ-006](../specs/production-plans.md#pln-req-006), [PLN-AC-005](../specs/production-plans.md#pln-ac-005) |

| Stan dostępny do sprzedaży / saleable stock | Część stanu dopuszczona do sprzedaży według procedury zakładu. Fizyczny zwrot nie oznacza automatycznego dopuszczenia; nie wolno drugi raz odejmować tego samego odpadu/zwrotu. | [STK-REQ-002](../specs/stock-inventory.md#stk-req-002), [SAL-AC-002](../specs/sales-returns.md#sal-ac-002) |
| Zdarzenie / `ActivityEvent` | Wersjonowany zapis faktu z tożsamością, czasem zajścia i zapisu, źródłem oraz kolejnością w strumieniu; zapis rzeczywisty ma autora. `manual` i izolowane `simulation` mają tę samą semantykę, nie wspólny rejestr produkcyjny. Start/stop nie dowodzi transferu ani zajęcia urządzenia. | [EVT-REQ-001](../specs/production-records.md#evt-req-001), [EVT-AC-008](../specs/production-records.md#evt-ac-008), [MAP-AC-001](../specs/flow-map-demo.md#map-ac-001) |
| Projekcja / projection | Odtwarzalny stan wyprowadzony z zatwierdzonych zdarzeń, wspólny dla źródeł ręcznych i symulowanych. Nie jest drugim ręcznie utrzymywanym modelem prawdy ani dowodem ruchu z animacji. Korekta wymaga spójnego przeliczenia zależności lub odrzucenia. | [EVT-REQ-009](../specs/production-records.md#evt-req-009), [EVT-REQ-002](../specs/production-records.md#evt-req-002), [EVT-AC-015](../specs/production-records.md#evt-ac-015) |
| Planowane obciążenie/rezerwacja zasobu / planned resource occupation | Zamiar harmonogramu CAPP, nie fakt pracy maszyny. Osobne wejście planistyczne; brak potwierdzenia wykonania pozostaje brakiem danych. | [EVT-REQ-013](../specs/production-records.md#evt-req-013), [MAP-AC-012](../specs/flow-map-demo.md#map-ac-012) |
| Rzeczywiste zajęcie zasobu / actual resource occupation | Potwierdzone przypisanie i zwolnienie konkretnego zasobu. `resource_reserved` w kontrakcie EVT oznacza właśnie zajęcie wykonawcze, nie plan. Znana pojemność podlega walidacji we wspólnej jednostce; nieznana nie oznacza bezpiecznej dostępności. | [EVT-REQ-013](../specs/production-records.md#evt-req-013), [EVT-AC-013](../specs/production-records.md#evt-ac-013) |
| Aktualność źródła / source freshness | Potwierdzenie, że źródło odpowiada, oceniane oddzielnie od ostatniego zdarzenia według jawnego interwału/progu adaptera. Błąd odczytu oznaczyć od razu; historyczny obraz stanu nie udaje bieżącego. | [MAP-REQ-012](../specs/flow-map-demo.md#map-req-012), [MAP-AC-011](../specs/flow-map-demo.md#map-ac-011) |
| Wiek zdarzenia / event age | Czas od ostatniego faktu produkcyjnego. Cztery godziny cichej fermentacji nie oznaczają awarii, jeżeli odczyty źródła są poprawne; pauza zegara demo nie jest awarią danych rzeczywistych. | [MAP-REQ-011](../specs/flow-map-demo.md#map-req-011), [MAP-AC-010](../specs/flow-map-demo.md#map-ac-010) |

## Granice interpretacji

Tożsamości osób i ich czas podlegają rolom, minimalizacji i retencji z [polityki prywatności](../engineering-assurance.md#ass-privacy) oraz [WRK-REQ-014](../specs/workforce.md#wrk-req-014). Historia techniczna nie ustanawia bezterminowej retencji danych osobowych. Nie identyfikować ani nie oceniać pracowników kamerami bez odrębnej oceny prawa i prywatności. Słownik nie potwierdza zgodności prawnej ani wdrożenia funkcji. [DEC-001](../decisions.md#dec-001) i [DEC-002](../decisions.md#dec-002) pozostają OPEN; definicja pojęcia nie wybiera precyzji mas ani podziału i porządku strumienia.
